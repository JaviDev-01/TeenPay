# 💸 TeenPay+

**TeenPay+** es una **aplicación web progresiva (PWA)** de gestión financiera personal diseñada específicamente para **adolescentes**, con un enfoque **educativo**, **visual** y **gamificado** 🎮📊.  
Su objetivo es ayudar a los jóvenes a **tomar el control de su dinero** de una forma **divertida, segura y fácil de entender**.

---

## 🚀 Características principales

- 📱 **Progressive Web App (PWA)**  
  Funciona en cualquier dispositivo (móvil, tablet o escritorio) y puede instalarse como una app nativa.

- 🎯 **Educación financiera para adolescentes**  
  Enseña conceptos clave como ahorro, gastos, presupuestos e ingresos de forma sencilla y práctica.

- 🕹️ **Gamificación**  
  Sistema de logros, recompensas y retos que motivan a mejorar los hábitos financieros.

- 📊 **Visualización clara del dinero**  
  Gráficas e indicadores intuitivos para entender fácilmente el uso del dinero.

- 🔐 **Entorno seguro**  
  Diseñado para un público joven, priorizando la privacidad y la protección de los datos.

---

## 🎓 Objetivo del proyecto

El objetivo de **TeePay** es fomentar la **responsabilidad financiera desde una edad temprana**, ayudando a los adolescentes a desarrollar habilidades económicas esenciales para su futuro 💡💰.

---

## 🛠️ Tecnologías

> Esta sección puede ajustarse según el stack utilizado en el proyecto.

- 🌐 Frontend: HTML, CSS, JavaScript

- ⚙️ Backend: Node.js / Firebase
